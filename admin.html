Manajemen histori perbaikan

Input Data Perbaikan Segmen

Masukkan rentang STA, jalur, lajur, tanggal, dan keterangan pekerjaan. Sistem otomatis membagi rentang tersebut ke segmen 200 meter agar menyatu dengan logika histori peta dan statistik.

Mode baca
Admin online: cukup masukkan kata sandi umum. Tidak perlu email, komputer utama, file .bat, atau jaringan yang sama. Data tersimpan di Supabase dan langsung digunakan oleh peta, statistik, Home, serta Tentang.

Masuk sebagai Admin

Semua admin masuk memakai satu kata sandi umum; email akun internal tidak perlu diketik.

Tambah histori perbaikan

Kolom bertanda * wajib diisi.

Dapat berupa tautan Google Drive, server internal, atau lokasi dokumentasi lain.
