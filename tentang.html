Tentang SurGem Maintenance

SurGem Maintenance adalah sistem informasi pemantauan (monitoring) kondisi pemeliharaan jalan tol berbasis peta digital (WebGIS) yang dirancang untuk memvisualisasikan progres pemeliharaan perkerasan jalan tol secara spasial dan temporal (berbasis waktu). Studi kasus platform ini difokuskan pada Ruas Jalan Tol Surabaya–Gempol (SurGem) sepanjang kurang lebih 43 kilometer, dengan cakupan pencatatan data pemeliharaan dari tahun 2023 hingga 2026.

Setiap segmen jalan diidentifikasi dan dicatat secara komprehensif, mencakup parameter rentang kilometer (STA), panjang penanganan, jenis perbaikan, serta dimensi waktu berupa bulan dan tahun penyelesaian pekerjaan. Informasi tersebut kemudian ditransformasikan ke dalam peta interaktif guna menyajikan visualisasi yang adaptif, sehingga kondisi riil dan rekam jejak (historical data) perbaikan pada setiap ruas dapat dievaluasi secara cepat, tepat, dan efisien.

Tujuan

  • Visualisasi Spasial Komprehensif: Menyajikan gambaran spasial yang menyeluruh dan interaktif terkait sebaran serta progres pemeliharaan jalan tol secara real-time.
  • Penelusuran Data Temporal (Histori): Mempermudah pemangku kepentingan dalam melakukan penelusuran riwayat perbaikan jalan tol berdasarkan periode waktu tertentu secara kronologis.
  • Transparansi dan Aksesibilitas Data: Mendukung keterbukaan informasi dan kemudahan retribusi data melalui penyediaan fitur unduh tabel atribut bagi pengguna.

Alur Pengembangan Sistem

Sistem ini dikembangkan melalui integrasi data spasial dan tabular dengan metodologi pengolahan sebagai berikut:

  1. Akuisisi Data: Mengumpulkan data spasial dalam format GeoJSON yang memuat lokasi gerbang dan jalur tol, beserta data atribut ringkasan pemeliharaan Scrapping, Filling, dan Overlay (SFO) resmi yang bersumber dari PT Jasa Marga (Persero) Tbk.

  2. Pengolahan dan Integrasi Data (GIS Processing): Melakukan kompilasi, pemeriksaan, penyelarasan (data cleaning), dan penggabungan (join/relate) antara data spasial dan data atribut SFO menggunakan perangkat lunak ArcGIS Pro. Tahapan ini dilakukan untuk membentuk satu kesatuan basis data spasial yang valid dan siap digunakan dalam sistem.

  3. Ekspor Data Spasial: Mengekspor hasil pemrosesan data dari ArcGIS Pro ke dalam format pertukaran data geografis terbuka, yaitu GeoJSON. Format tersebut digunakan agar geometry dan data atribut dapat dibaca melalui aplikasi berbasis web.

  4. Implementasi Kode dan Visualisasi (WebGIS Deployment): Mengintegrasikan file GeoJSON hasil pengolahan ke dalam arsitektur program WebGIS. Aplikasi dikembangkan menggunakan pustaka peta interaktif Leaflet.js, dengan dukungan HTML, CSS, dan JavaScript melalui lingkungan pengembangan Visual Studio Code untuk menghasilkan antarmuka pemetaan yang interaktif dan responsif.
